# ⚙️ OS Lab — Operating System Visualizer

OS Lab is an interactive web-based platform that helps students understand Operating System concepts through **visualizations and step-by-step simulations**.

Instead of only studying algorithms theoretically, users can provide their own input, select an algorithm, and visually observe how it executes step-by-step.

## 📚 Modules

### ✅ Completed

**1. Page Replacement**
- FIFO
- LRU
- Optimal
- LFU

**2. CPU Scheduling**
- FCFS
- SJF
- SRTF
- Priority Scheduling
- Round Robin

**3. Disk Scheduling**
- FCFS
- SSTF
- SCAN
- C-SCAN

- C-LOOK
